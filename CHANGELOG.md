# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.1] — 2026-09-16

### Fixed
- Агрегаты сделок больше не группируются по `currency`: на Entity API поле недоступно в `groupBy`. Воронка — по `stageId`, KPI — итоги без разреза валют; код валюты для оформления берётся из последних сделок.

## [1.2.0] — 2026-09-16

### Changed
- Данные CRM читаются ключом приложения `vibe_app_` и сессией из `X-Vibe-Authorization`; без сессии — 401, личного ключа в рантайме нет.
- Суммы форматируются по валюте сделки; при усечении агрегата показывается предупреждение.
- Имена ответственных запрашиваются по id из списка сделок, а не полным справочником пользователей.

## [1.1.1] — 2026-09-03

### Changed
- Справочники CRM и последние сделки читаются через `POST /v1/batch`; при отказе пакетного вызова остаётся последовательный запасной путь.
- При 429 / 502 / 503 запросы к API повторяются с паузой по `Retry-After` (401 и 403 не ретраятся).
- Ошибки 401, 403, 429 и 502 показываются отдельными понятными сообщениями на дашборде и в разделе «Помощь».

## [1.1.0] — 2026-09-02

### Added
- Корпоративное оформление SafeKit, строка версии в подвале и вкладка «Помощь».
