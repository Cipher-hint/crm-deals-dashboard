# Дашборд сделок CRM

Встраиваемое приложение для Битрикс24 (платформа Вайбкод): аналитика по сделкам CRM от лица текущего сотрудника.

## Что показывает

- сводку по стадиям воронки: количество и сумма в валюте сделки;
- KPI: сумма открытых сделок, число выигранных за период, средний чек;
- последние 20 сделок;
- фильтр по дате создания (7 / 30 / 90 дней, всё время, произвольный диапазон);
- предупреждение, если агрегат API усечён.

Данные читаются через VibeCode Entity API с ключом приложения `vibe_app_` и сессией из `X-Vibe-Authorization`. Личный `vibe_api_` в рантайме не используется. Без сессии дашборд отвечает 401.

## Локальный запуск

```bash
cp .env.example .env
# впишите VIBE_APP_KEY=vibe_app_…
npm install
npm start
```

Откройте `http://localhost:3000`. Без заголовка сессии `/api/dashboard` вернёт 401 — так и задумано.

## Деплой на VibeCode

1. Galaxy-приложение: `POST /v1/infra/servers` с `name`, `source`, `runtime: node20`, `start: node server.js`.
2. В `env` передайте только `VIBE_APP_KEY` (ключ авторизации приложения). Личный `vibe_api_` в контейнер не кладите.
3. На каждый деплой передайте полный `env` заново (платформа не хранит секреты между выкладками).
4. OAuth-приложение: скоупы `crm`, `user`, `placement`, режим ключа `READONLY`, место `LEFT_MENU`.
