Что делает приложение

Дашборд собирает аналитику по сделкам CRM текущего портала и показывает её на одной странице: воронку по стадиям, сумму открытых сделок, число выигранных за период, средний чек и список последних сделок. Данные читаются через API Вайбкод от лица владельца ключа приложения. Отдельный вход для сотрудников не нужен: все, кому открыта страница, видят одну и ту же выборку.

Как открыть дашборд

  1. В левом меню Битрикс24 откройте пункт Дашборд сделок.
  2. Если пункта нет — откройте каталог приложений портала и карточку Дашборд сделок CRM.
  3. Прямая ссылка: https://app-bfeac934a09d.vibecode.bitrix24.tech. Снаружи это защищённый сервер Вайбкод: сначала вход через Bitrix24.

Ключевые показатели

  • Сумма открытых сделок — сделки периода, у которых поле «закрыта» равно нет. Под карточкой — их количество.
  • Выиграно за период — сделки, созданные в выбранном периоде и сейчас находящиеся в успешной семантике стадии (S, обычно стадии «Успех» / WON). Ниже — сумма этих сделок.
  • Средний чек — сумма выигранных, делённая на их число. Если выигранных нет, берётся средняя сумма всех сделок периода.

Сводка по стадиям воронки

Строки — текущие стадии сделок, созданных в выбранном периоде. Для каждой стадии: человекочитаемое название, код stageId, воронка (категория), количество и сумма. На портале несколько воронок (квалификация, лицензия, продление, услуги) — они идут одним списком с подписью воронки. Полоска справа пропорциональна сумме стадии в выборке, не общему объёму CRM.

Фильтр по периоду создания

Фильтр действует по дате создания сделки (не по дате перехода в «успех»). Пресеты: 7 / 30 / 90 дней и «Все время». Можно задать обе границы вручную и нажать «Применить».

  • Указана только одна дата — приложение попросит заполнить вторую или очистить обе.
  • «С» позже «По» — диапазон отклоняется, данные прошлого запроса не подменяются пустым экраном без объяснения.
  • Даты считаются по календарю Москвы (UTC+3): с 00:00:00 по 23:59:59 выбранных суток.

Последние сделки

До 20 сделок периода, новые сверху: название, сумма, стадия, ответственный, дата создания. Это не полный реестр CRM — для полной выгрузки используйте стандартный список сделок Битрикс24.

Чьи сделки видны

Выборка ограничена правами владельца личного API-ключа, которым развёрнуто приложение. Это не персональная воронка каждого сотрудника: коллега увидит те же цифры, что и владелец ключа. Если сделка не попадает в CRM-права этого пользователя в Битрикс24, её не будет и на дашборде.

Если что-то пошло не так

  • «Нет доступа: ключ недействителен или сессия истекла» — откройте дашборд из левого меню портала и обновите страницу. Если ошибка остаётся, ключ приложения нужно перевыпустить (это делает администратор).
  • «Недостаточно прав для чтения CRM» — у приложения нет скоупов crm и user, либо у владельца ключа нет прав на сделки. Проверьте карточку приложения и права CRM.
  • «Превышен лимит запросов» — портал временно ограничил частоту API. Подождите 10–30 секунд и нажмите «Применить» ещё раз; повторять сразу смысла нет.
  • «Портал Битрикс24 или Вайбкод временно недоступен» — сбой на стороне портала или платформы. Обновите страницу через минуту. Если портал за корпоративным фаерволом — см. раздел для ИТ/ИБ.
  • Пустой экран / «Не удалось получить данные» — нет связи с API. Отключите VPN/прокси, обновите страницу (Ctrl+F5), откройте приложение из меню Битрикс24, а не из чужой вкладки.
  • KPI нулевые, хотя сделки есть — сузьте или расширьте период. По умолчанию стоят последние 30 дней: сделки старше этого окна не входят в выборку. Нажмите «Все время».
  • Выигранных меньше, чем в отчёте CRM — дашборд считает выигранными сделки, созданные в периоде и сейчас успешные. Сделка, созданная год назад и закрытая сегодня, в фильтр «30 дней» не попадёт.
  • Пункта в левом меню нет — обновите портал или откройте каталог приложений. Приложению нужно место встраивания LEFT_MENU и коммерческий тариф портала.
  • Старая вёрстка после обновления — Ctrl+F5 в окне приложения, чтобы сбросить кеш браузера.

Информация для ИТ/ИБ-службы

Приложение размещено на платформе Битрикс24 Вайбкод (galaxy-контейнер, режим Black Hole). Интерфейс открывается в iframe портала или по HTTPS-адресу приложения. Данные CRM читает сервер приложения через API Вайбкод; ключ хранится только в окружении сервера, в браузер не попадает.

Заявка для ИТ/ИБ (можно скопировать):

Прошу разрешить HTTPS (443) для работоспособности приложения «Дашборд сделок CRM» на портале Битрикс24:

  Domain — app-bfeac934a09d.vibecode.bitrix24.tech
           vibecode.bitrix24.tech
           oauth.bitrix.info
  Ports  — 443
  Traffic Direction — Incoming / Outgoing

Исходящий трафик (браузер сотрудника → сервер приложения):
  загрузка HTML/CSS/JS дашборда и запросы /api/dashboard.

Исходящий трафик (сервер приложения → Вайбкод / Битрикс24):
  чтение сделок, стадий, пользователей через REST-обёртку https://vibecode.bitrix24.tech/v1/*
  (на портале это обращения к /rest/* от имени владельца ключа).

Входящий трафик:
  только HTTPS к адресу приложения; SSH и прямой доступ в интернет закрыты (Black Hole).

WebSocket и длинные пуллы не используются — короткие HTTPS-вызовы.
Запись в CRM приложение не выполняет (только чтение).
